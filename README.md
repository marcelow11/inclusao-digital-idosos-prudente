# Portal Acesso Fácil – Inclusão Digital para Idosos (Presidente Prudente - SP)

Projeto desenvolvido para a disciplina **Atividade Extensionista II: Tecnologia Aplicada à Inclusão Digital – Projeto** do curso **CST em Gestão da Tecnologia da Informação** (Centro Universitário Internacional UNINTER).

- **Autor:** Marcelo Vargas Thomazini (RU: 3997589)
- **Local de Aplicação:** Presidente Prudente, Estado de São Paulo (SP)

## Objetivo
Disponibilizar uma interface web simplificada e acessível para facilitar o acesso do público da terceira idade a serviços públicos essenciais (saúde, previdência, farmácia popular e canais de emergência), aplicando diretrizes de Desenho Universal e normas **WCAG 2.1 (Nível AAA)**.

## Funcionalidades Implementadas
- **Redimensionamento Tipográfico Dinâmico (`A+` / `A-`):** Ampliação de fontes até 200% sem quebra de leiaute.
- **Modo de Alto Contraste:** Alternância instantânea para fundo escuro com tipografia amarela de alta legibilidade.
- **Cartões Ampliados com Ícones Descritivos:** Redução da jornada de navegação de 8 para 3 etapas intuitivas.
- **Modal de Confirmação Explícita:** Prevenção contra toques acidentais antes do redirecionamento externo.

## Tecnologias Utilizadas
- **HTML5 Semântico** (atributos ARIA e estrutura acessível)
- **CSS3 Responsivo** (variáveis de tema, Grid Layout e foco visível)
- **JavaScript (ES6+)** (manipulação do DOM para controles de acessibilidade)

## Como Executar
Basta abrir o arquivo `index.html` diretamente em qualquer navegador web moderno (desktop ou smartphone), sem necessidade de servidor ou dependências externas.
